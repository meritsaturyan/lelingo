# Le Lingo

Հայերեն ինտերֆեյսով ֆրանսերենի ուսուցման հավելված (A1–B2)։

## Գործարկում

```bash
npm install
npm run dev
```

Բացեք [http://localhost:3000](http://localhost:3000)

## Հնարավորություններ

- Onboarding և մակարդակի ընտրություն (A1–B2)
- Տեղադրման թեստ (20 հարց)
- Շաբաթական ուսումնական պլան
- Բառապաշար, քերականություն, լսել, թելադրություն, խոսել
- Կիրակնօրյա շաբաթվա թեստ
- XP, streak և առաջընթաց (localStorage)

## Տեխնոլոգիաներ

Next.js · TypeScript · Tailwind CSS · Web Speech API (TTS / STT)
